# Project figures

This directory contains publication-style figures from the NSCLC CAF-associated transcriptional program and tumor-state analysis.

- `Figure1_CAF_signature_validation.png`: CAF-associated gene-program assessment in the discovery dataset.
- `Figure2_CAF_vs_Byers76_EMT.png`: Association between the CAF-associated score and the primary EMT-associated signature.
- `Figure3_CAF_vs_Wong_stemness.png`: Association between the CAF-associated score and the secondary stemness-associated signature.
